# CodePIddy 数据存储模型

- 状态：已确认
- 日期：2026-09-16

## 项目文档

位置：项目 `.codepiddy/`。

用途：需求、设计、任务拆解、实现说明、Bug 说明、修复说明和审核报告。

这些文件是 Agent 交接事实源，默认存在并适合进入 Git。

## 本地运行数据

位置：`%LOCALAPPDATA%\CodePIddy\`。

用途：Pi session、完整聊天、日志、运行状态、权限审计、写锁、凭据、缓存和内部索引。

## 唯一规则

```text
协作结果 -> 项目文档
运行细节 -> 本地数据
```

不做可选同步、不做双向权威源、不把完整 session 导出进项目。
