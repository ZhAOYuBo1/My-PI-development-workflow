# 参考项目拆解：dsh-effort-dial

参考仓库：`https://github.com/WONGIII/dsh-effort-dial`

本地只读克隆：`E:\mypi-refs\dsh-effort-dial`

审查版本：`39620be1a819f247078b83bfb88052a8f8d7d7fc`

用途：借鉴思考强度滑块的场动画与交互手感，不复制其 DeepSeek Harness 槽位、插件注册和模型列表逻辑。参考仓库在用户验收后可以删除，本文件保留设计结论。

## 1. 视觉模型

它不是“进度填充 + 一个滑块”，而是一列从滑块发射出去的行进波锋：

- 波锋从滑块出发，经过轨道时点亮像素列，离开后逐渐衰减。
- 波锋前沿上升快、尾部衰减慢，所以有明确的方向感和持续覆盖。
- 稀疏的流星增强速度感，但它们共享一个速度，避免随机抖动和互相追尾。
- 最高档落点有一次短促扫光，随后回到稳定的高阶场，不平移地永久闪烁。

## 2. 交互模型

- 点击和键盘步进沿缓动曲线滑到目标。
- 拖拽直接跟手，残余偏移自行溶解。
- 每个档位是磁吸锚点：经过时略被拖住，离开后释放，但不会卡死。
- 滑块始终略大于轨道，轨道负责场，滑块负责抓取。

## 3. 对 CodePIddy 的适配

只取三部分：

1. 波锋场：低档慢而疏，高档快而密。
2. 最高档落点扫光：一次短促反馈，不常驻强闪烁。
3. 磁吸拖拽：提高档位停靠手感，但不改变 `onChange` 契约。

不采用的部分：

- 紫黑轨道和持续高饱和光晕，改为浅色界面里的蓝色强调和局部紫色。
- DeepSeek Harness 的单槽位替换、模型目录读取和弹层列表。
- 原项目 32px 轨道、34px 滑块和 320px 弹层尺寸；CodePIddy 使用 14px / 16px / 现有 236px 弹层。

## 4. 实现边界

- renderer 只新增 `ThinkingDialField.tsx`，不改模型选择、IPC 或会话逻辑。
- canvas 只在思考强度弹层打开时运行，页面隐藏时暂停。
- `prefers-reduced-motion` 下只绘制静态场。
